# PaintingEditor-Emu

**iOS MCPE (v0.16.2) Emulator** 用の Mod です。設置した絵画の絵を、好きな写真・画像・GIF（アニメーション）に変え、
絵画の大きさも変えられます。

## 使い方

| | 開き方 |
|---|---|
| PC（マウス・キーボード） | 絵画に照準を合わせて**右クリック** |
| スマホ（iPhone をつないだタッチ操作） | 絵画に近づく（4 ブロック以内）と、画面下の操作ボタンの位置に **「開く」** が出るのでタップ。近くに絵画がいくつかあるときは、いちばん近い絵画が対象です（ボタンは 1 つだけ） |

1. 開くと、PC ではファイルを選ぶ画面、スマホでは写真・ファイルを選ぶ画面が出ます（PNG / JPEG / GIF / BMP）
2. 選ぶとプレビューになります（背景は半透明のグレー）
   - 中央の絵画は**ドラッグで回転**でき、裏や横からも見られます
   - 左右の縦長の矢印ボタンで大きさを切り替えます：1×1 → 2×1 → 1×2 → 2×2 → 2×4 → 3×3 → 3×4 → 4×3 → 4×4（**幅×高さ**、ブロック単位）
   - 大きさの表示の上にあるボタンで、画像の向きを変えられます
     - 左（曲がった矢印）：押すたびに画像を**時計回りに 90 度回転**
     - 右（← ● →）：画像を**左右反転**（もう一度押すと元に戻ります）
3. 右上の **×** か **Esc**（スマホは ×）で、そのとき表示している大きさ・向きに決定して閉じます

どのボタンも、押すとゲームのボタンと同じクリック音が鳴ります。

### 自動で閉じるとき

| 状況 | 結果 |
|---|---|
| まだ画像を選んでいないうちに、ダメージを受けた／死んだ／ファイル選択をキャンセルした | 絵画は何も変えずに閉じます（開いているファイル選択画面も閉じます） |
| 画像を選んだあとに、ダメージを受けた／死んだ | **そのとき選んでいた大きさ・向き**に決定して閉じます |

死んだときは、死亡画面が出る前にこの画面を閉じるので、死亡画面とは重なりません。

## 絵の表示

- 画像は（回転・反転したあと）絵画の縦横比に合わせて**中央を切り抜いて**貼ります（引き伸ばしません）。透明な部分は透明のまま表示されます
- GIF はアニメーションします（フレームごとの表示時間どおり）
- 絵画の裏と縁は、元の絵画と同じ木の板のテクスチャです

## 保存

- 選んだ画像は `<データ>\home\Documents\PaintingEditor\` に保存されます（ファイル名は中身から作るので、同じ画像は 1 つだけ保存されます）
- 絵画には、ワールドのデータ（絵画の NBT）に `PaintingEditor = "幅x高さ:ファイル名"`（回転・反転しているときは
  `"幅x高さ/回転回数/反転:ファイル名"`、回転回数は時計回り 90 度単位の 0〜3、反転は 0 か 1）が追加されます。ワールドを閉じて開き直しても、エミュレータを再起動しても残ります
- 大きさが元のゲームにもある大きさ（1×1, 2×1, 1×2, 2×2, 4×3, 4×4）のときは、その大きさのバニラの絵柄名で保存されます。この Mod を外してワールドを開くと、同じ大きさのバニラの絵画になります（2×4・3×3・3×4 は 1×1 のバニラの絵画になります）
- 画像を大きく読み込みすぎないよう、静止画は長い辺 512 ピクセル、GIF は 256 ピクセル（フレームが多いときはさらに小さく）に縮小して表示します。保存されるのは元のファイルです

## マルチプレイ

LAN マルチプレイ（IP 指定での参加も含む）に対応しています。**ホストと参加する人の両方がこの Mod を入れている**と、
編集した絵が全員の画面に同じように表示されます。

- ホストが編集した絵画も、参加した人が編集した絵画も、全員に反映されます（大きさ・回転・反転も同じ）
- 編集の内容はホストのワールドに保存されます。参加した人が編集した絵画も、ホストのワールドに残ります
- 画像は自動で送られます。持っていない画像があると、ホストから受け取ります（参加した人が選んだ画像は、いったんホストに送られてから
  ほかの人に配られます）。受け取るまでのあいだ、その絵画は無地のキャンバスで表示されます
- あとから参加した人にも、それまでに編集された絵画がすべて反映されます
- 同じ絵画を同時に編集した場合は、あとから決定したほうになります

通信はゲームのマルチプレイの接続をそのまま使います（別のポートやファイアウォールの設定は不要です）。

Mod を入れていない人がいる場合：

| | 結果 |
|---|---|
| ホストだけ Mod なし | 参加した人が編集しても、その人の画面にしか反映されません（ホストのワールドにも保存されません） |
| 参加した人の一部が Mod なし | その人には通常の絵画に見えます（大きさがバニラにある大きさならその大きさ、2×4・3×3・3×4 は 1×1）。ゲームはそのまま遊べます |

## 仕様・制限

- 編集した絵画は、壁が足りない大きさでも外れて落ちません（バニラの絵画は壁に収まらないとアイテムになります）。叩けば普通に壊せます
- PC のサバイバルモードで右クリックが届く距離は、バニラのエンティティに届く距離と同じです（クリエイティブより短い）
- スマホの「開く」ボタンはゲームの操作ボタン（ボートの「降りる」などと同じもの）を使っています。ボートや動物など、ほかのエンティティに照準が合っているときはそちらのボタンが優先されます

## ビルド（Visual Studio）

1. Visual Studio の「ローカル フォルダーを開く」でこのフォルダを開きます
2. 構成「MCPE mod (arm64, Release)」を選んで「すべてビルド」
3. できた `PaintingEditor.dylib` は自動で `%LOCALAPPDATA%\iOS-MCPE-0.16.2\mods\` にコピーされます

必要なものはエミュレータの Mod と同じです（Python と `py -m pip install ziglang`）。
エミュレータを `--data <フォルダ>` で起動する場合は、CMake の `MCPE_DATA_DIR` をそのフォルダにしてください。

**エミュレータ側の対応が必要です。** GIF を選べるファイル選択画面（`emu_pick_media_begin`）と、画面を閉じたときに
ファイル選択画面を閉じる機能（`emu_pick_image_cancel`）は、この Mod に合わせてエミュレータに追加したものです。
古いエミュレータでも動きますが、その場合 PC のファイル選択は PNG / JPEG / BMP だけになり、
ダメージで閉じたときにファイル選択画面が開いたまま残ります（選んでも無視されます）。

## ファイル

| ファイル | 内容 |
|---|---|
| `src/main.cpp` | 初期化とフック（右クリック、スマホの「開く」ボタン、死亡画面の前に閉じる） |
| `src/paintings.cpp` | 編集した絵画の管理（大きさ、保存・読み込み）とワールドでの描画 |
| `src/screen.cpp` | 編集画面（ファイル選択、プレビュー、大きさボタン、×ボタン） |
| `src/assets.cpp` | 選んだ画像の保存、読み込み（別スレッド）、テクスチャ（GIF はフレームごと） |
| `src/net.cpp` | マルチプレイ（編集内容と画像を、ゲームの接続〈RakNet〉で独自のメッセージとして送受信） |
| `src/image.cpp` | 画像のデコード（PNG / JPEG / BMP / GIF） |
| `src/game.h` | 使っているゲームの関数のアドレスとデータの配置（Android 版のシンボルと照合して調べたもの） |
| `third_party/stb/stb_image.h` | 画像デコーダー [stb_image](https://github.com/nothings/stb) v2.30（パブリックドメイン） |
| `include/`, `cmake/` | エミュレータの `mod-template` と同じもの（`emu_mod.h` は画像選択の関数を追加した版） |

GUI のテクスチャは、ゲームに入っているものだけを使っています（新しく作ったテクスチャはありません）。
クリック音はゲームのボタンと同じ `random.click`（`MinecraftClient::playUI`）です。

| 部品 | テクスチャ（`textures/gui/newgui/`） |
|---|---|
| ボタン（通常・カーソルを合わせたとき・押したとき） | `buttons/border/base`, `hover`, `basePress` |
| 大きさボタンの矢印 | `arrowLeft`, `arrowRight` |
| 回転ボタンのアイコン | `undoArrow`（左右反転して表示し、時計回りの矢印にしています） |
| 左右反転ボタンのアイコン | `Rotate`（← ● →） |
| × ボタン（PC） | `XHover`, `XPress` |
| × ボタン（スマホ） | `textures/gui/spritesheet` の (60, 0) と押したとき (78, 0)、18×18。チェストやかまどのスマホ用画面の右上の × と同じ |
| プレビューの絵画の裏と縁 | `textures/painting/kz` |
